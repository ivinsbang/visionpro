# Spatial and design assets

- `reality-composer/`: source projects for authored spatial scenes.
- `models/`: source or exportable 3D models.
- `design/`: reviewed layouts, interaction references, and visual specifications.

This scaffold includes no supplied or generated brand assets. Record provenance
and usage permissions alongside assets when they are introduced.

Runtime assets belong in the relevant app or Swift package resource bundle once
targets exist. Use Git LFS for large binary assets when an asset pipeline and
repository host are selected; LFS is not configured yet.
